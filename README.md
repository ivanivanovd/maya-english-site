# Английский с Майей

Сайт-визитка преподавателя английского языка Майи. Главная страница — `index.html`, фотография — в `assets/`.

## Публикация на Cloudflare Pages

- Подключите репозиторий `ivanivanovd/maya-english-site` через Workers & Pages → Create application → Pages → Connect to Git.
- Production branch: `main`
- Framework preset: `None`
- Build command: `exit 0`
- Build output directory: `.`

В `tilda-zero-blocks/` лежат отдельные HTML-файлы секций для импорта в Zero Block. Инструкция — в `tilda-zero-blocks/README.txt`.
